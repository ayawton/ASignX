# Sign Strike UI direction

ASign Learn now has two complementary paths: structured modules and an arcade for practicing fingerspelling. The arcade is a browser-only interaction prototype; no recognition model is connected.

Palette: cobalt #2962F5, ink #18294C, pale sky #EDF3FF, white #FFFFFF, yellow #FFE66D, muted blue #AFC5ED. Outfit remains the display face and DM Sans the interface face.

Layout: left-aligned page introduction and learning-mode navigation above a large playfield, with a narrow camera/input rail. On mobile the arena comes first and the controls follow.

```text
[ ASign Learn / Arcade                    Back to modules ]
[ Modules                              Sign Strike       ]
[ Ready. Sign. Fire.                   Mode / pace       ]
[ Score       Combo       Wave       Shields       Time  ]
[                                        ][ Camera       ]
[  Falling letter / word targets          ][ preview      ]
[                                        ][              ]
[              Sign-powered ship         ][ Simulated    ]
[                                        ][ sign controls]
[ Game feedback                           ][ How to play  ]
```

The memorable element is the falling-target playfield. Space-game styling stays inside the arena, while surrounding controls use the established light UI. Targets are letters in Alphabet patrol and letter sequences in Word defense, so the interface never presents English word labels as ASL translations. Camera access is optional and local. Only simulated input affects the game. Arcade scores remain separate from lesson completion and XP.
